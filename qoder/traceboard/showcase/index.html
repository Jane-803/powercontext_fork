THE PROBLEM

从“说过”到“找得到”

每周整理进度时，信息往往要从多个地方重新拼接。检索不到原始资料，就很难判断结论是否可靠。迹点让工作记录、任务状态和周报共享同一份可回查的数据。

01记录结论与来源
02检索并筛选证据
03关联任务进度
04生成可核对周报

CORE FEATURES

围绕真实项目记录设计

证据归档

保存笔记、会议、成果和阻塞，附上日期及来源链接，避免结论脱离上下文。

组合检索

用 seekdb 全文索引查找关键词，同时按项目、类型和日期缩小范围。

进度与周报

任务关联证据 ID。按选定时间段汇总原始记录和任务状态，导出 Markdown。

IMPLEMENTATION

seekdb 在核心流程中工作

证据写入 seekdb 的 `evidence` 表。用户搜索时，服务端直接执行全文索引查询和结构化条件过滤；周报再次读取同一批记录，因此新增内容可在后续使用中复用。

体验应用需要按仓库说明启动 seekdb 和本地服务。本站为公开作品展示页，不承载数据库 API。

SELECT id, title, content
FROM evidence
WHERE project = ?
AND occurred_on >= ?
AND MATCH(title, content) AGAINST(?);
